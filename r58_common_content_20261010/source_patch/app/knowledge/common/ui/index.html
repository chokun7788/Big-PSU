กรอกข้อมูลจริงของศูนย์ ตรวจทาน แล้วเผยแพร่ให้แชทบอทอ่าน

รายการข้อมูล

เริ่มจากหมวดเกม หรือหมวดที่ต้องการ

ข้อมูลที่ไม่รู้ให้คงสถานะ “ไม่ทราบ” ระบบจะไม่ตีความว่าไม่มีบริการหรือราคาเป็นศูนย์

ฟิลด์ที่มี ★ ต้องยืนยันก่อนเผยแพร่ บางหมวดต้องสร้างรายการอ้างอิงก่อน เช่น โซน → เครื่อง → บริการ → เกมที่ติดตั้งในบริการ

ห้ามใส่ข้อมูลลูกค้า สลิป รหัสผ่าน หรือข้อมูลส่วนตัวที่ไม่ได้อนุญาตให้เผยแพร่

ใช้ a-z, ตัวเลข, _ : - อย่างน้อย 3 ตัว เปลี่ยนชื่อได้โดยคงรหัสเดิม
ชื่อเรียกอื่น / Alias จริง (ไม่จำเป็นต้องใส่ทุกคำสะกดผิด)
ช่วงวันที่ข้อมูลมีผลราคา ตารางเวลา วันปิด กติกา และข่าว ต้องยืนยันช่วงวันที่ก่อนเผยแพร่
