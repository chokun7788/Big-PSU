# ทดลอง R73 และกรอกข้อมูลช่วยเลือกคำตอบ

## เปิดใช้ในเครื่องนี้

เปิด `Open-New-Chat.cmd` → แชทพอร์ต **8105** ป้าย **R73**

ปิดด้วย `Stop-New-Chat.cmd` ของโฟลเดอร์ R73 แก้ข้อมูลร่างด้วย `Open-Data-Editor.cmd` ที่พอร์ต **8106**

ใช้ runtime Python จากโฟลเดอร์ R69 ที่อยู่ข้างกัน และ Ollama/โมเดลตามระบบเดิม จึงต้องเก็บโฟลเดอร์ R69 ไว้ ชุดนี้เป็นสำเนาพัฒนาสำหรับเครื่องนี้ ยังไม่ใช่แพ็กเกจ portable หรือ release production ใหม่

## เพิ่มข้อมูลแบบไม่ต้องเขียนคำถามทุกแบบ

ในหมวด **คำถามที่พบบ่อย / กฎ / ขั้นตอนปฏิบัติ** มีช่องทางเลือกชื่อ **ช่วยแชทเลือกหัวข้อคำตอบ**

กรอกเนื้อหาจริงของหมวดนั้นให้ครบก่อน ช่องนี้ช่วยเลือกข้อมูล ไม่ใช่ที่ใส่คำตอบ และไม่ใช่การอนุมัติข้อเท็จจริง

| ช่อง | กรอกอย่างไร | ตัวอย่าง |
|---|---|---|
| ผู้ใช้ถามเรื่องลักษณะไหน | เลือก “ถามว่าใช้/นำมาได้ไหม” หรือ “ถามวิธีแก้สิ่งที่ทำผิด” | วิธีแก้สิ่งที่ทำผิด |
| เรื่องหรือสิ่งของที่คำตอบนี้ครอบคลุม | เพิ่มหนึ่งแถวต่อเรื่อง ใส่ชื่อไทย/อังกฤษ ไม่ต้องเขียนทุกประโยคคำถาม | สลิป / slip |
| เป็นของส่วนตัวหรือไม่ | เลือกของส่วนตัวเมื่อกฎจำกัดเฉพาะของที่ผู้ใช้นำมา | ไม่จำกัดเจ้าของสิ่งของ |
| ใช้กับบริการทั่วไปหรือการแข่งขัน | เลือกขอบเขตตามเอกสารจริง | บริการทั่วไปของศูนย์ |

ตัวอย่าง **แก้แนบสลิปผิด**: เนื้อหา steps คือวิธีส่งสลิปตามข้อมูลที่เจ้าของยืนยันไว้ ส่วนข้อมูลช่วยเลือกให้ task=วิธีแก้, subject=สลิป/slip, ownership=ไม่จำกัด, context=บริการทั่วไป เมื่อถาม “แนบสลิปผิดทำไง” หรือ “I uploaded the wrong slip. How do I fix it?” ระบบจะอ่านขั้นตอนที่บันทึกไว้

ตัวอย่าง **กฎอุปกรณ์ส่วนตัว**: กรอก answer หรือ decision/details/เงื่อนไขจริง แล้วตั้ง task=ถามว่าใช้/นำมาได้ไหม, subjects=ชื่ออุปกรณ์ที่กฎครอบคลุมทีละแถว, ownership=ของส่วนตัว, context=บริการทั่วไป

ถ้าเปลี่ยนคำตอบ ให้แก้รายการเดิมและบันทึกฉบับร่างใหม่ ประวัติเดิมยังอยู่ หาก profile ไม่ตรงเอกสารหรือยังไม่มั่นใจ ให้คงสถานะ **ยังไม่ทราบ** ไม่ต้องกรอกเพื่อให้ผ่าน

## ขอบเขตที่รองรับรอบนี้

ข้อมูลช่วยเลือกแบบใหม่นี้เพิ่มสำหรับ **permission และ correction** เท่านั้น หมวดเกม ราคา ปฏิทินและกติกายังใช้ตัวอ่านเฉพาะหมวดที่มีอยู่ ไม่ได้ย้ายทุกหมวดมาใช้สองประเภทนี้

กรณีที่ยังไม่มีคำตอบเฉพาะ เช่น โอนเกิน ผ่อนชำระ ระยะเงินถึง และอายุเข้าใช้ ระบบจะแจ้งว่าเรื่องใดยังยืนยันไม่ได้พร้อมช่องทางจริง การบอกว่ายังยืนยันไม่ได้ไม่ใช่นโยบายอนุญาต/ห้ามใหม่

ข้อมูลตัวอย่างที่ใช้ทดสอบรายการใหม่และแก้ revision อยู่ใน `verification/profiles02` แยกจากฐานที่แชท R73 ใช้
