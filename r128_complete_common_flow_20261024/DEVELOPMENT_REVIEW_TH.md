# สิ่งที่พบระหว่างทำ R128 และเหตุที่ต้องตรวจรวม

เอกสารนี้แยกข้อผิดพลาดที่เกิดระหว่างพัฒนาออกจากผลรุ่นส่งมอบ ดูรอบล่าสุดใน FINAL_RUN.json และ DELIVERY_REPORT_TH.md ไม่ใช้ผลจาก attempt เก่ามาปนเป็นคะแนนปัจจุบัน

## ข้อผิดพลาดที่พบและแก้

1. `eat` ไป match กลางคำว่า Beat Saber ทำให้คำถามเกมไปตอบอาหาร แก้ขอบเขตคำอังกฤษและเพิ่ม negative checks ของชื่อเกม
2. คำถามกฎ CS2 ที่มีคำผิดไปเลือกแค่หัวข้อ Game Settings แก้การอ่าน full clause จาก source terms และห้าม heading อย่างเดียวผ่านคำถามสิทธิ์
3. คำถาม Tekken กับราคา PC มี `ans` แทน `and` ทำให้เสียหนึ่งความต้องการ แยก task ตามคำเชื่อมที่กู้คืนได้แล้ว
4. รายการอุปกรณ์โซน Nintendo แสดงแค่เครื่อง ไม่รวม TV/โซฟา แก้การอ่าน inventory จากความสัมพันธ์โซนของทุก equipment_model
5. Slot จำนวนคนผ่านตัว resolver แต่ไปถึงตัวคำนวณแล้วกำกวม เพราะ alias สั้น `PSU` ไปผูกกับจำนวนของกลุ่มก่อนหน้า แก้ให้ตัวนับใช้ช่วง alias ที่ไม่ทับกันเช่นเดียวกับ audience binder และตรวจยอดจริงผ่าน HTTP
6. อัตราหลายบริการที่เทียบเท่ากันถูกคิดว่าเลือกบริการไม่ได้ แก้ให้เปรียบเทียบผลคำนวณสำหรับระยะเวลาที่ผู้ใช้ถาม ภายใต้หน่วย validity และ confirmation เดียวกัน ไม่รวมอัตราที่คำนวณไม่ได้เข้าด้วยกัน
7. คำว่า “ครึ่งวัน” ถูกตัวแปลงเลขคำเปลี่ยนเป็น 0.5 วัน ทำให้แพ็กเกจเหมาไม่เข้าตัวอ่าน แยก lexical period ของแพ็กเกจออกจากเลขหน่วยทั่วไป
8. การแก้ guard เพื่อไม่ให้ราคาเดิมยึดโจทย์ใหม่ ทำให้การเปลี่ยนเป็น PS5 ถูกกันไปด้วย เพราะ PS5 ผูก equipment entity ได้ แก้ให้การแทน platform ภายใน task ราคาทำได้ ขณะที่โจทย์ปุ่มใหม่ยังแยกได้
9. วันที่ภาษาไทยพร้อมช่วงเวลา 15:00–16:00 ถูก date parser อ่านบางส่วนเป็นวัน/เดือน แยก clock range ก่อนอ่านวัน และตรวจการเปลี่ยนเครื่องโดยรักษาวัน/ช่วงเวลา
10. คำถามค่าเหมาที่ชัดยังผ่านโมเดลและกลายเป็นราคาต่อชั่วโมง แก้ native rental frame ให้ถึง rental_package โดยตรง
11. คำถามตำแหน่งคนและที่ตั้งอุปกรณ์ชัดเจนยังต้อง inference แก้ source-bound frames ก่อนโมเดล ส่วน inverse role ยังใช้ privacy/source guards เดิม
12. การถามอัดวิดีโอในศูนย์ไม่ควรตอบสิทธิ์จากนโยบาย capture ในเกม แก้ให้คืน source scope และ partial โดยไม่อนุมานสิทธิ์ถ่ายบุคคลหรือสถานที่
13. UI ตารางถูกแล้วแต่แถบ sources ยุบเป็นป้าย draft เดียว แก้ให้จัดกลุ่มหลักฐานพร้อมช่วง citation เช่น S1–S19 และไม่แสดง local paths
14. การแก้ sources รอบแรกขาด import `re` เกิด HTTP 500 ใน test installation ตรวจพบจากรอบ HTTP รวม แก้แล้วและรันรวมใหม่ เก็บ attempt ที่ผิดใน `api_1792827500022721200` ไว้ ไม่ติดตั้ง attempt นั้นทับ preview ที่ใช้งานได้

## ปรับเกณฑ์ตรวจรับ

- เพิ่ม actual HTTP conversations ของกลุ่มราคา เหมา live window และการเปลี่ยนเรื่อง เพื่อไม่ให้ unit check เฉพาะ state ถูกตีความว่าผลปลายทางถูกแล้ว
- ชุดรับงานต้องตรวจทั้ง response body และ HTTP errors; acceptance script ไม่ถือว่ารันครบจำนวนแปลว่าผ่าน
- source/UI ต้องไม่เปลี่ยนขณะรันชุดส่งมอบ ตรวจ hash ก่อน–หลัง และตรวจ source เดียวกันอีกครั้งเมื่อ activate port ที่ผู้ใช้ใช้
- source-add/edit/withdraw tests ใช้ฐานแยก ไม่ใส่ fixtures หรือเปลี่ยน approvals ของข้อมูลจริง
- เก็บ attempt ที่ผิดไว้สำหรับตรวจย้อนหลัง ผลส่งมอบอ้างเฉพาะรอบล่าสุดที่ผ่าน source freeze และข้อกำหนดที่ระบุ

ข้อสรุปจากงานนี้คือการตรวจแต่ละชิ้นอย่างเดียวไม่เพียงพอ จุดเชื่อม state → query → rate grouping → reader → API → UI ต้องผ่านด้วยกัน การตรวจรวมจึงพบสาเหตุที่ตัวตรวจเฉพาะชิ้นมองไม่เห็น และรุ่นส่งมอบต้องยืนยันจากปลายทางจริงอีกครั้ง
