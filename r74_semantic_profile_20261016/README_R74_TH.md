# ใช้สำเนาพัฒนา R74

## เปิดแชท

เปิด **Open-New-Chat.cmd** ในโฟลเดอร์นี้ ปกติใช้ `http://127.0.0.1:8107/` ปิดด้วย **Stop-New-Chat.cmd** ของโฟลเดอร์เดียวกัน

ต้องเก็บโฟลเดอร์ `PSU_Esports_Chat_New_R69` ข้างกัน เพราะใช้ Python runtime จากชุดนั้น และต้องมี Ollama/โมเดลตามการตั้งค่าเดิม ชุดนี้เปิด LLM อยู่ ยังไม่ใช่แพ็กเกจ portable สำหรับแจกเครื่องอื่น

สคริปต์สร้างที่เก็บ runtime/logs/state ของตัวเอง และตรวจ identity ก่อนใช้พอร์ตหรือปิดโปรเซสเดิม ไม่หยุดเว็บของชุดอื่นเมื่อพอร์ตชนกัน

## แก้ข้อมูล

เปิด **Open-Data-Editor.cmd** ใช้พอร์ต **8108** ข้อมูลอยู่ใน `system/data/knowledge/common.sqlite` ของ R74 แยกจากชุดเก่า หากแก้ผ่าน editor ให้ตรวจว่าใช้โฟลเดอร์ที่ตั้งใจ ข้อมูลใหม่จะไม่ถูกคัดกลับ R73 อัตโนมัติ

ฟอร์มกลางยังเหมือน R73: กรอกเนื้อหาจริงและหลักฐานใน FAQ/กฎ/ขั้นตอนก่อน หากมี query_profile ให้ระบุ task, subject ไทย/อังกฤษ, ownership และ context ไม่ต้องกรอกประโยคถามผิดทุกแบบ

R74 ไม่เพิ่มช่องที่เจ้าของต้องกรอกและไม่เปลี่ยนราคา/นโยบาย/เกม/คำแปลในฐาน มีเพียงโค้ดเลือกข้อมูลและแยกส่วนคำตอบที่พัฒนาต่อ ข้อมูลมีสถานะร่างและการอนุมัติตามเดิม
