# ข้อมูลที่ต้องขอเพิ่ม — PSU Esports Studio - Phuket Chatbot

ตรวจจาก source และสถานะล่าสุดวันที่ 2026-10-01 หลังรอบ r27

## เริ่มตอบตรงไหนก่อน

เริ่มข้อ 1–2 ก่อน เพราะเป็นข้อกฎที่ขัดกันหรือข้อความต้นฉบับขาด แล้วตอบข้อ 3 เมื่อต้องการรับรองและเปิดใช้ข้อมูล V2 ส่วนข้อ 4–6 เติมตามข้อมูลที่มีได้ งานเก็บสถานะจองจริงในข้อ 7 เก็บไว้ภายหลังตามคำขอเดิม

ช่องว่างหมายถึงยังไม่ได้ตอบ ไม่ถือเป็นการยืนยันหรืออนุญาต ตัวเลือก “ยังไม่แน่ใจ/ยังไม่มีนโยบาย” ใช้ได้ พร้อมระบุผู้ที่ตัดสินใจเรื่องนั้นได้
