# คู่มือช่องกรอกข้อมูลทุกหมวด

สถานะ: แบบออกแบบ 3.0 ยังไม่เชื่อมเว็บใช้งานจริง; templates เป็น draft ที่กรอกไม่ครบได้ แต่ยัง Publish ไม่ได้

เจ้าของกรอกชื่อ/ค่าจริงและแหล่งข้อมูลผ่านฟอร์ม ชื่อ key และ record_id ให้ระบบสร้าง/เลือก ไม่จำเป็นต้องพิมพ์ JSON เอง

ช่องที่ยังไม่ทราบเลือก unknown; ห้ามกรอก 0/false/ไม่มีแทน unknown. ช่องอ้างอิงใช้ dropdown จากทะเบียนเดียวกัน

publish_core = จำเป็นก่อนเผยแพร่ความสามารถหลักของ record; ช่องอื่นยังตอบเป็น partial ได้ แต่ไม่ถือว่าข้อมูลครบทุก facet
