# เทส LLM กับแชทอัตโนมัติจากไฟล์เดียว

## ใช้ยังไง

ดับเบิลคลิก **Open-Automatic-LLM-Test.cmd** แล้วรอผล ไม่ต้องพิมพ์คำถามเอง ไม่ต้องเปิด Ollama ด้วยมือ ไม่ต้องสั่ง stop/start แชทแยก

ตัวรันทำตามลำดับ:

1. ตรวจว่าไฟล์ R78 เป็นโค้ด R81 ที่ผ่านการตรวจ และเชื่อมต่อบริการในเครื่องได้
2. ถ้า R78 ยังไม่เปิด ให้เปิดผ่าน launcher เดิม ถ้าเปิดอยู่แต่ยังโหลดโค้ดเก่าหรือไม่ได้เปิด LLM ให้ stop/start เฉพาะ R78 ที่ตรวจตัวตนและ launch token ได้
3. ถ้า Ollama ยังไม่เปิดและยืนยันได้ว่าไม่มีบริการรับการเชื่อมต่อ ให้เปิด Ollama ที่ติดตั้งไว้เบื้องหลัง ถ้าติดต่อได้อยู่แล้ว ใช้ตัวเดิม
4. ตรวจว่ามีโมเดลที่แชทตั้งค่าไว้ ไม่ดาวน์โหลดโมเดลหรือโปรแกรมให้เอง
5. เรียกโมเดลจริงให้สร้าง READY เพื่อยืนยันการสร้างข้อความและ warm-up ด้วย num_ctx 3072 เก็บเวลา cold/warm ตามที่ API ส่งกลับ การทดสอบสร้าง READY ยังไม่ใช่การพิสูจน์ว่าโมเดลเลือกข้อมูลได้ถูก
6. ส่งคำถามไทย/อังกฤษ 14 ข้อความผ่าน `/api/chat` พร้อม session แยก ตรวจคำตอบ การถามต่อ การปฏิเสธแล้วเปลี่ยนเรื่อง เงื่อนไขเพิ่ม และวันเปิด–ปิด
7. เก็บทุกคำถาม/คำตอบ เหตุผลการเลือก เวลา HTTP และ error ลงโฟลเดอร์ใหม่ใต้ `results` แล้วสรุปไทย/อังกฤษให้อัตโนมัติ

ไม่ใช่ full test สองหมื่นข้อ เป็นชุดทดสอบระบบจริงเฉพาะจุดที่กำลังแก้ ไม่ได้บังคับให้ทุกคำถามผ่าน LLM เพราะระบบจริงบางคำถามตอบตรงจากข้อมูลได้ แต่จะนับแยกว่าคำถามใดเรียก selector จริง โมเดลตอบกลับหรือหมดเวลา และผ่านรูปแบบผลลัพธ์หรือไม่

## ผลที่ต้องแยกดู

- `llm_enabled_verified`: ตรวจได้ว่าเปิด LLM ในแชท
- `real_model_generation_verified`: เรียก Ollama ให้สร้างข้อความจริงสำเร็จ
- `chat_selector`: จำนวนคำถามที่เรียก selector จริง รูปแบบผลลัพธ์ผ่าน และข้อผิดพลาด โมเดลคืน JSON ถูกไม่ได้พิสูจน์ว่าเลือกความหมายถูกเสมอ
- `all_answer_contracts_passed`: คำตอบผ่านเงื่อนไขเนื้อหาของชุดนี้
- `by_language`: ผลไทย/อังกฤษ
- `CHAT_TURNS.jsonl`: เนื้อหาเต็มและเหตุผลเลือกข้อมูลของแต่ละคำถาม

ผลเวลาแชทเป็นหลัง warm-up ที่บันทึกไว้ ห้ามใช้ไปอ้างว่าเปิดเครื่องครั้งแรกทุกคำถามเร็วเท่ากัน

หากพบ WinError 10013 ตัวรันจะหยุดก่อนเริ่มบริการหรือเปลี่ยนเส้นทางเชื่อมต่อ ไม่แก้ firewall ไม่ยกระดับสิทธิ์ ไม่ใช้ทางอ้อม ผลที่มีเก็บไว้ ไม่ตีความว่า Ollama หรือ Chatbot เสีย

## ทำไมต้องดับเบิลคลิกจาก Windows ตอนนี้

ตัวระบบเทสอัตโนมัติได้ เหมือนตัวรันเก่า ข้อจำกัดที่พบในรอบนี้คือเครื่องมือจากแชทไม่ได้รับสิทธิ์เชื่อม loopback (การขอสิทธิ์ network ได้ผล null) จึงสั่งการทดสอบ HTTP/LLM จริงจากเครื่องมือนี้ไม่ได้ การเปิดตัวรันเองจาก Windows หนึ่งครั้งจะให้มันทำขั้นตอนที่เหลืออัตโนมัติ เมื่อเสร็จบอกว่า “รัน R82 แล้ว” เพื่ออ่านผลและแก้ต่อ

ตัวรันไม่เปลี่ยนโค้ดแอป/ฐานข้อมูล/approvals/นโยบาย ไม่ลบ log เดิม มีเฉพาะข้อมูลสถานะและ log ใหม่ที่ launcher เดิมและคำถามทดสอบสร้างตามปกติ หากเริ่ม Ollama ให้จะเปิดทิ้งไว้เพื่อให้แชทใช้งานต่อ
