# เปิดใช้และเก็บผล R81

โค้ดรอบนี้ติดตั้งเพิ่มในแชท R78 เดิม พอร์ต 8115 โดยยังเปิด LLM ไว้ ไม่ต้องย้ายโฟลเดอร์ ไม่ต้องโหลดโมเดลใหม่

## ทำครั้งเดียวหลังได้รับแจ้งว่าติดตั้งเสร็จ

1. เปิดหน้าต่าง Ollama ที่รันอยู่ไว้ตามเดิม
2. ดับเบิลคลิก **Open-R81-Restart-and-Check.cmd** ในโฟลเดอร์นี้
3. ไฟล์นี้จะเรียกตัวปิด R78 เดิมที่ตรวจว่าเป็นโปรเซสของแชทชุดนี้ รอให้ปิด แล้วเปิดใหม่ผ่านตัวเปิดเดิม จากนั้นถามชุดสั้นไทย/อังกฤษรวม 14 ข้อความ
4. รอจนขึ้น `Results saved:` ผลอยู่ใน `user_results` โฟลเดอร์ใหม่พร้อมเวลาของรอบนั้น
5. บอกในแชทนี้ว่า “รัน R81 แล้ว” เพื่อให้อ่านผล วิเคราะห์เวลาจริง และข้อผิดพลาดต่อ

ถ้าปิดหรือเปิดไม่สำเร็จ ตัวช่วยจะหยุดและแสดงเหตุผล ไม่บังคับปิดโปรเซสที่พิสูจน์ตัวตนไม่ได้ ไม่แก้ firewall ไม่ดาวน์โหลดโมเดล ไม่ลบ log เก่า

ถ้าได้ปิด–เปิด R78 ใหม่เรียบร้อยแล้ว สามารถใช้ **Open-R81-Check.cmd** ซึ่งตรวจอย่างเดียวได้ ตัวตรวจเทียบ fingerprint ของโค้ดที่เซิร์ฟเวอร์โหลด หากเป็นโค้ดเก่าจะไม่ทดสอบต่อ

## จะเห็นอะไรในผล

- `HEALTH.json`: ตัวตนแชท ข้อมูลโค้ดที่โหลด และสถานะเปิด LLM
- `TURNS.jsonl`: คำถาม/คำตอบจริง เวลา HTTP และเหตุผลเลือกข้อมูลของแต่ละข้อความ
- `RESULTS.json`: ผ่าน/ไม่ผ่าน แยกไทย/อังกฤษ และรายการความล้มเหลวของ selector แยกจากข้อผิดพลาดของเนื้อหา
- `SUMMARY.md`: สรุปอ่านง่าย

ชุดนี้ตรวจการถามยืนยันอุปกรณ์ส่วนตัว สลิป การเปลี่ยนเรื่อง เงื่อนไขเพิ่มเติม และคำตอบวันนี้เปิดไหม ไม่ใช่ full test และไม่พิสูจน์ความถูกต้องของทุกหมวด

## เหตุที่ยังต้องเปิดตัวช่วยจาก Windows

เครื่องมือในแชทนี้เชื่อม loopback ถูกปฏิเสธด้วย WinError 10013 แต่ผลจากตัวตรวจที่ผู้ใช้เปิดเองก่อนหน้าพิสูจน์ว่า R78 และ Ollama เชื่อมได้ การทดสอบภายในจึงแยกจาก HTTP จริง ไม่อ้างว่าทดสอบเว็บผ่านเพียงเพราะชุดภายในผ่าน
