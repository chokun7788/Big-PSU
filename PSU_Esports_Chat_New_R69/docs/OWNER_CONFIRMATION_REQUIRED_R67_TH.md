# คำถามที่ยังต้องใช้หลักฐานหรือคำยืนยันของศูนย์

ข้อมูลที่หาได้จากไฟล์เดิมย้ายให้แล้ว ไม่ขอให้กรอกใหม่ทั้งชุด ไม่ต้องยืนยันสถานะจองจริง พักเที่ยง 12:00–13:00 หรือ VR 30 นาทีใช้ช่องเต็มชั่วโมงซ้ำ

## ประเด็นที่พบใหม่จากการเทียบไฟล์จริง

### 1. ขอบเขตความรับผิดชอบเมื่ออุปกรณ์เสียหาย

- ไฟล์ `data/rules/penalty_rules.jsonl` รายการ `rule_damage_responsibility`
- ไทยระบุเมื่อทำอุปกรณ์เสียหาย โดยไม่เขียนเงื่อนไขผิดวิธีหรือประมาทชัดเจน
- อังกฤษระบุ `through improper or negligent use`
- คำถาม: **ค่าปรับ/ค่าชดเชยใช้เฉพาะความเสียหายจากการใช้ผิดวิธีหรือประมาท หรือใช้กับความเสียหายทุกกรณี? กรณีเครื่องเสียเองระหว่างใช้ตามปกติอยู่ในเงื่อนไขใด?**
- ตัวเลขค่าปรับเดิมยังอยู่ครบ ไม่ใช้การแปลเลือกนโยบายฝั่งใดแทนเจ้าของ เก็บทั้งสองข้อความไว้ใน source_variants และแสดงข้อจำกัดในคำตอบ

### 2. ผังปุ่มที่แหล่งเดิมระบุว่ายังไม่มี

- Delta Force บน PS5 และ Pokémon Champions บน Nintendo Switch: ไฟล์เดิมมีเพียงสถานะ mapping unavailable
- ต้องการภาพหรือ export ผังปุ่ม **ของเวอร์ชันที่ติดตั้งจริง พร้อมแพลตฟอร์ม ชื่อ preset และวันที่ตรวจ** ก่อนเติมผังปุ่มที่ยังไม่มี
- เกมอื่นที่มีปุ่มอยู่แล้วได้ย้ายทุกแถว รวมหมายเหตุการตรวจและข้อจำกัดเดิม ไม่ต้องกรอกปุ่มทั้งหมดใหม่

## ประเด็นเดิมที่ยังไม่ได้รับข้อเท็จจริงเพิ่ม

1. **ราคา PS5/Switch/Cockpit/VR หลัง 31 มีนาคม 2026 ใช้ตารางใด เริ่ม/สิ้นสุดวันไหน?** ไม่ยืดอายุตารางเก่าให้เอง
2. **ราคา PC 0/25/70 บาทที่มีอยู่แล้วมีผลตั้งแต่วันใด และยังใช้ถึงเมื่อไร?** ไม่ต้องยืนยันตัวเลขใหม่ เพราะกู้จากข้อมูลที่เคยยืนยันแล้ว
3. **ราคาเหมาครึ่งวันและเต็มวันครอบคลุมกี่โมงถึงกี่โมง/กี่ชั่วโมง และมีผลช่วงใด?** ไม่ตั้ง 4/8 ชั่วโมงจากชื่อแพ็กเกจ
4. **เวลาเปิดพื้นที่ศูนย์ต่างจากช่วงที่จองเล่นได้หรือไม่ โดยเฉพาะหลัง 16:00 ถึง 18:00?** เก็บความต่างในต้นฉบับไว้
5. **ข้อเปลี่ยนวันเมื่อจ่ายแล้ว กับข้อไม่ให้เลื่อนแทนคืนเงิน ใช้คนละกรณีอย่างไร?** ต้องมีเงื่อนไขแยก เช่น จองผิดวัน/ขอเลื่อนภายหลัง/เหตุศูนย์ปิด
6. นโยบายที่ต้นฉบับยังไม่ยืนยัน เช่น อายุ/ผู้ปกครอง บัญชีเกม การติดตั้ง/mod ชดเชยเวลาที่เครื่องขัดข้อง มาสาย/ต่อเวลา และถ่ายทำ/สตรีม ยังคง unknown ไม่สรุปจากคำถามคล้ายกัน

## งานเทคนิคที่ยังไม่ต้องถามเจ้าของ

- ทดสอบ actual LLM และ HTTP เมื่อ sandbox อนุญาต socket
- นำโค้ดและฐานร่างเข้าโปรเจกต์เมื่อได้รับสิทธิ์เขียนผ่านระบบ
- ตรวจ residual content/source alignment และ schema metadata ที่อนุมานได้จากหลักฐาน โดยระบุว่าเป็น derived metadata
- ตรวจคำแปลส่วนอื่นที่ยังไม่ได้เทียบรายช่อง ไม่ถือว่าการย้ายข้อมูลหรือ literal guard เท่ากับ owner review

ไม่มีการติดต่อเจ้าของหรือส่งข้อความภายนอกในรอบนี้ รายการนี้เป็นข้อที่ต้องนำไปขอข้อมูลภายหลัง
