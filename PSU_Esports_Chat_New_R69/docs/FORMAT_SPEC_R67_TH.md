# Format กลาง R67 — คู่มือหมวดและช่องข้อมูล

สถานะ: ข้อมูลจริงที่ย้ายมาเป็นร่างสำหรับตรวจและทดลอง ยังไม่ใช่ release production

## วิธีเริ่มใช้งาน

เปิด Open-R67-Drafts.cmd ในโฟลเดอร์นี้ เลือกหมวดและรายการเดิมเพื่อแก้ไข หรือเพิ่มรายการใหม่ ทดสอบในช่องทดลองร่าง ข้อมูลที่กรอกยังไม่เปลี่ยนเว็บแชทปกติจนกว่าจะผ่านการตรวจและเผยแพร่

## ตัวอย่างสำคัญ

### เพิ่ม/แก้เกม

ใช้รายการเดิมเมื่อแก้คำอธิบายเกม เพิ่มชื่อ/ชื่อเรียก แนวเกม วิธีเล่น และคำบรรยายต้นฉบับ หากเปลี่ยนเป็นอีกภาคหรือ edition ต้องแยกตัวตนให้ชัด การมีรายละเอียดเกมไม่เท่ากับศูนย์ติดตั้ง ต้องเชื่อมเกมกับบริการในหมวด game_service

### เพิ่ม/แก้ปุ่ม

เลือกเกมและแพลตฟอร์มก่อน เพิ่มทีละแถว เช่น ชื่อปุ่ม A, รายการปุ่ม [A], action เร่งเครื่อง, notes กดค้างไว้เพื่อเร่งเครื่อง ถ้าแถวหนึ่งมีหลายการกระทำหรือไม่ทราบ gesture ให้เลือก unknown และเก็บคำอธิบายตามต้นฉบับ ห้ามเลือก press แทนข้อมูลที่ไม่ทราบ ชื่อ A / B ไม่รับรองว่ากดพร้อมกัน

### เพิ่ม/แก้ราคา

เลือกบริการและกลุ่มผู้ใช้ กรอกบาทในหน้าเจ้าของ ระบบเก็บหน่วยย่อยเอง ระบุเวลา หน่วยคิด สูตร และวันมีผลตามประกาศ ไม่คูณราคาหรือกำหนดวันเอง การแก้สร้าง revision ใหม่ เก็บราคาเดิมในประวัติ ไม่เปลี่ยนราคาที่หมดอายุให้เป็นปัจจุบัน

### เพิ่ม/แก้กติกา

เลือกรายการแข่งขันและเกม แยกหัวข้อ ข้อความเต็ม และข้อที่ต้องอ่านร่วมกัน อย่าตัดข้อยกเว้นหรือท้ายข้อ ใช้ source_order รักษาลำดับเมื่อเลขหัวข้อซ้ำ facets เป็นการจัดหมวดค้นหา ไม่ใช่กฎใหม่ และไม่ได้รับรองว่าข้อความครอบคลุมทุกกรณี

### ข้อมูลหลายภาษา

ใส่ไทย/อังกฤษแยกกัน ช่องที่ไม่มีคำแปลจะระบุรอแปล ไม่ใช้คำตอบสั้นภาษาอังกฤษแทนรายละเอียดไทยที่ยาวกว่า คำแปลโดย agent ยังแยกจากการยืนยันโดยเจ้าของ

## ทุกหมวดที่ระบบรองรับ
