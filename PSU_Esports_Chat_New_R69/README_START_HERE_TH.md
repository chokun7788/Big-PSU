# เปิดแชทชุดใหม่ R69

ชุดนี้เป็นหน้าแชทแยกที่อ่านข้อมูล Format กลางซึ่งย้ายและตรวจต่อถึง R68 แล้ว ใช้ข้อมูล 602 รายการ โดยเก็บโครงการเดิมและ R68 ต้นฉบับไว้

## เริ่มใช้งาน

1. ดับเบิลคลิก **Open-New-Chat.cmd**
2. รอจนเปิดหน้าเว็บ `http://127.0.0.1:8101/` แล้วเริ่มถามได้
3. ปิดแท็บแล้วโปรแกรมยังทำงานเบื้องหลัง หากต้องการหยุด ให้เปิด **Stop-New-Chat.cmd**

ตัวอย่างคำถาม:

- PS5 มีเกมอะไรบ้าง
- กฏตอนเเข่ง cs2 มีอะไรมั่ง
- General Adult PC 2 ชั่วโมงกี่บาท → ถ้าเป็นศิษย์เก่าล่ะ
- List all controls for eFootball on PlayStation / PS5. → What does R2 do?
- PC1 วันนี้เวลา 15:00 ว่างไหม — ต้องเข้าถึง WordPress ได้เพื่อยืนยันสถานะสด

แชทใช้ประวัติในแต่ละบทสนทนา ข้อมูลและประวัติของหน้าแชทเก่าไม่ได้ถูกนำมาปนกัน

## เพิ่มหรือแก้ข้อมูล

1. เปิด **Open-Data-Editor.cmd** จะเปิดหน้ากรอกข้อมูลพอร์ต 8102
2. เพิ่มรายการโดยเลือกหมวด หรือค้นหารายการเดิมแล้วกดแก้ไข
3. กรอกข้อเท็จจริงและที่มา อ่านตัวอย่างและคำอธิบายช่องในหน้าฟอร์ม ไม่ทราบให้เลือกว่ายังไม่ทราบ
4. บันทึก การแก้รายการเดิมให้ใช้รหัสเดิม ระบบเก็บเป็นฉบับใหม่และเก็บฉบับก่อนหน้าไว้
5. กลับหน้าแชทใหม่แล้วถามอีกครั้ง แชท R69 อ่านฉบับร่างล่าสุดจากฐานเดียวกัน ไม่ต้องคัดลอกฐานใหม่หรือแก้โค้ดเพื่อเพิ่มข้อมูล
6. หากทดสอบผลของการแก้ไข ให้ถามแบบระบุรายการเต็มในบทสนทนาใหม่ก่อน เพื่อแยกผลของประวัติเดิมออกจากข้อมูลใหม่

หน้ากรอกนี้แก้เฉพาะฐานในโฟลเดอร์ R69 การปิดหน้าต่างที่รันตัวแก้ข้อมูลจะหยุดเฉพาะหน้ากรอก

คู่มือช่องเดิมอยู่ใน `docs/FORMAT_SPEC_R67_TH.md` และช่องเพิ่มเติมอยู่ใน `docs/FORMAT_GUIDE_R68_TH.md` สำเนาคู่มือเหล่านี้ยังอ้างถึงตัวเปิด R67/R68: **สำหรับชุดนี้ให้ใช้ตัวเปิดสามไฟล์ที่ระบุด้านบน**

## สถานะของชุดนี้

- เป็น **ชุดตรวจข้อมูลที่ย้าย ยังไม่ใช่ชุดเผยแพร่ที่เจ้าของอนุมัติ** จึงมีแถบแจ้งสถานะบนหน้าแชท
- ไม่มีการกดอนุมัติหรือเผยแพร่แทนเจ้าของ ข้อมูลที่ไม่ทราบหรือขัดกันยังต้องคงสถานะนั้น
- รองรับฟอร์ม 24 หมวด จำนวนข้อมูลจริงแต่ละหมวดต่างกัน บางหมวดยังไม่มีข้อมูล ห้ามตีความว่ามีครบทุกช่องแล้ว
- การเพิ่มข้อมูลสำเร็จไม่ได้รับประกันว่าจะเข้าใจคำถามใหม่ทุกสำนวน ควรลองคำถามที่คาดว่าจะใช้และตรวจคำตอบกับข้อมูลจริง
- เปิดตัวช่วย LLM เป็นค่าเริ่มต้น ใช้บริการโมเดลในเครื่องที่มีอยู่ ชุดนี้มี Python แต่ **ไม่ได้คัดลอกหรือดาวน์โหลดโมเดล** หากบริการโมเดลไม่พร้อม ส่วนอ่านข้อมูลที่ระบุชัดยังทำงานได้ ส่วนที่ต้องใช้โมเดลอาจขอรายละเอียดเพิ่ม
- สถานะจองสดอ่าน WordPress ผ่านตัวเชื่อมเดิม ต้องมีเครือข่ายและสิทธิ์เข้าถึงที่ถูกต้อง การทดสอบรอบนี้ใช้สถานะจำลองที่รู้ผล ไม่ใช่การยืนยัน WordPress ใหม่

## เมื่อเปิดไม่ได้

- ถ้าพอร์ต 8101 มีโปรแกรมอื่นใช้ ตัวเปิดจะแจ้งและไม่ปิดโปรแกรมนั้น สามารถใช้ PowerShell เรียก `Start-New-Chat.ps1 -Port 8103` ได้
- หากแจ้งว่าสิทธิ์ไม่อนุญาตเชื่อมต่อ socket หรือเชื่อมต่อ localhost ไม่ได้ ให้ตรวจข้อจำกัดเครือข่ายของเครื่อง/โปรแกรมที่เปิด ระบบจะไม่แสดงว่าเปิดสำเร็จจากการสร้าง process เพียงอย่างเดียว
- สภาพแวดล้อมของผู้ช่วยในรอบนี้ปฏิเสธการเชื่อมต่อ HTTP ไป localhost จึงยังไม่ยืนยันการใช้งานผ่านเบราว์เซอร์จริง ให้เปิดตัวเปิดจาก Windows ของผู้ใช้เพื่อใช้งานและตรวจขั้นตอนนี้
- เก็บข้อความแจ้งเตือนและไฟล์ server-*.err.log ใน runtime/logs ไว้ใช้วิเคราะห์ อย่าทับ log เดิม
