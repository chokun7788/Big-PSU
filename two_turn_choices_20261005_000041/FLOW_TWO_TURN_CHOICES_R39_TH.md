# Flow การตอบชื่อสั้นหลังถามยืนยัน — r39.3

วันที่ทำงานจริง: 6 ตุลาคม 2026 เวลาไทย โฟลเดอร์หลักฐานคงชื่อเดิม `20261005` เพื่อไม่ย้ายหรือทับผลก่อนหน้า

## 1. เป้าหมาย

เมื่อผู้ใช้ถามรายละเอียดโดยยังขาดชื่อเกม บริการ หรือหมวด ระบบต้องถามส่วนที่ขาด เมื่อผู้ใช้ตอบเพียงชื่อนั้น ระบบต้องทำงานตามคำถามเดิม ไม่เริ่มตีความชื่อเป็นคำถามใหม่ทุกครั้ง

ตัวอย่าง: “ขอดูปุ่มควบคุมเกม” → ถามชื่อเกม → “VALORANT” → ตอบปุ่มควบคุม VALORANT

## 2. ลำดับที่ใช้จริง

1. รับข้อความ ภาษา session และรหัสรอบจากเว็บ
2. อ่านประวัติของ session จาก parent process เก็บ `mode` ของคำตอบไว้ด้วย เพื่อแยกถามปุ่มจากถามรายละเอียดเกม
3. ตรวจราคาแบบ typed plan: ถ้ากำลังรอเลือกบริการ ให้คงกลุ่มผู้ใช้และตัวกรองเดิม
4. ตรวจการเลือกเกมของกติกาแข่งขัน: คงรายละเอียด/หัวข้อ/ภาค/ปีที่ผู้ใช้ระบุ
5. ตรวจข้อความตอบชื่อจากคำถามล่าสุด:
   - ก่อนหน้าถามชื่อเกมเพื่อดูปุ่ม → เติมชื่อในงานดูปุ่ม
   - ก่อนหน้าแสดงรายชื่อเกม → ชื่อบริการสั้นใช้กรองรายชื่อเฉพาะโซน
   - ก่อนหน้าถามเลือกเกมในตระกูล → เลือกได้จากชื่อที่เสนอและยังต้องคงงานเดิม
   - ก่อนหน้าถามเลือกเรื่องของบริการ → `เกม / อุปกรณ์ / ราคา / จอง` และอังกฤษ `games / equipment / prices / booking` เติมหมวดให้บริการเดิม
6. ถ้าข้อความเป็นคำถามใหม่ชัดเจน เช่น “VALORANT คืออะไร” ให้เปลี่ยนงาน ไม่มีการบังคับให้เป็นปุ่มเพราะคุยเรื่องปุ่มมาก่อน
7. ก่อนค้นและตอบ ตรวจเลขภาคที่ติดกับชื่อเกมในรายการ ถ้าเลขภาคไม่มีหลักฐานใน aliases ของรายการเกม ให้แจ้งว่ายังไม่ยืนยัน ไม่เปลี่ยนเลขด้วยความคล้ายของตัวอักษร
8. ดำเนินงานตามหมวดและภาษา คืนคำตอบพร้อมแหล่งข้อมูล/สถานะไม่พบข้อมูล
9. บันทึกคำถามที่ผู้ใช้พิมพ์ คำถามหลังเติมบริบท โหมด หมวด งาน trace และการส่งคำตอบ

## 3. ข้อจำกัดการตีความชื่อ

| เงื่อนไข | วิธีจัดการ |
|---|---|
| ชื่อสั้นตรง aliases ทั้งคำ | รับเป็นตัวเลือกของงานที่กำลังรอ |
| ชื่อเกมพิมพ์คลาดเคลื่อน | ใช้ resolver เดิม ต้องได้ชื่อเดียว คะแนนอย่างน้อย 0.90 และส่วนต่างอย่างน้อย 0.08 |
| ชื่อบริการคลาดเคลื่อน เช่น cockpik | ใช้ service matcher เดิมกับข้อความสั้น จำกัดความกำกวมและไม่แก้เลขเครื่อง |
| พิมพ์ชื่อภาค เช่น TEKKEN 9 | ไม่เปลี่ยนเป็นภาค 8; ตรวจรายการก่อนตอบ |
| ชื่อไม่มีในรายการ เช่น Minecraft หลังถามปุ่ม | คงงานปุ่มและแจ้งไม่มีข้อมูลที่ยืนยัน แทนการแสดงรายชื่อเกมทั้งหมดหรือถามชื่อซ้ำเหมือนยังไม่ได้รับชื่อ |
| ระบุเกมนอกตัวเลือกตระกูล | ไม่ผูกว่าเป็นเกมในตระกูลนั้น |
| คำถามใหม่เต็มประโยค | ใช้เจตนาใหม่ |
| session คนละชุด / หมดอายุ / เปลี่ยนเรื่อง / turn ที่ไม่อนุญาตใช้บริบท | ไม่ยืมตัวเลือกจากงานเก่า |

คะแนนความมั่นใจของเส้นทางเป็นคะแนนการตัดสินใจว่าจะใช้ทางใด ไม่ใช่หลักฐานว่าข้อมูลราคา กติกา หรือปุ่มตรงกับการใช้งานจริงของศูนย์แล้ว

## 4. เงื่อนไขตรวจคำตอบ

ต้องตรวจทั้งสองรอบ ไม่ใช่แค่ชื่อเป้าหมายปรากฏในข้อความ

- รอบแรกถามเลือกในกรณีที่ต้องถาม ไม่ตอบรายชื่อเกมแทนคำขอปุ่ม
- รอบสองได้หมวดและงานที่ถูกต้อง เช่นปุ่มต้องเป็นคำตอบปุ่มจริง ไม่ใช่แค่คำอธิบายเกม
- เลือก PC แล้วไม่มีหัวข้อเกมของ PS5/Nintendo ปะปน เลือก Cockpit แล้วไม่แสดงทุกโซน
- ราคาบุคคลภายนอกคงกลุ่มนักศึกษาต่างสถาบันและบุคคลทั่วไป ไม่เปลี่ยนเป็นนักศึกษา PSU หรือราคา 0
- กติกาที่ขอรายละเอียดคง `full_sections` พร้อมการแบ่งหน้าและระบุส่วนที่ขาดคำแปล
- ชื่อผิดรุ่น/ไม่มีข้อมูลไม่ถูกแทนด้วยคำตอบของรุ่นหรือเกมอื่น
- ตรวจคำถามใหม่ การเปลี่ยนเรื่อง และแยก session

## 5. การทบทวนและแก้จากผลจริง

1. ตรวจ r38.5: 36 บทสนทนา เกณฑ์ครบทั้งสองรอบผ่าน 23/36 พบปุ่ม/โซน/การเลือกหมวดอังกฤษ/ตระกูลเกม
2. r39: แก้การคงงานเดิม ผ่านเคสปกติ 36 และเพิ่มเติม 17 แต่ negative test พบ TEKKEN 9 ตอบภาค 8 จากตัวค้นหา
3. r39.1–r39.2: เพิ่มการป้องกันเลขภาคและชื่อไม่ตรง พบ alias สั้น `evil` ชน Resident Evil 4 ใน unit test จึงเลือก match ที่เจาะจงกว่าก่อน และพบ Minecraft ตกไป catalog/ถามชื่อซ้ำ จึงคงงานปุ่มและแยกสถานะไม่มีข้อมูล
4. r39.3: ทดสอบผ่านเว็บและเก็บผลฉบับส่งมอบในรายงานคู่กัน ผลระหว่างพัฒนาที่ผิดยังคงอยู่ในหลักฐาน

## 6. สิ่งที่ยังไม่ได้ครอบคลุม

Flow นี้ยังใช้ประวัติและโหมดคำตอบในหลายหมวด ไม่ได้ย้ายทุกหมวดมาเป็น typed state เดียวกัน ข้อความเลือกที่ยาวมาก ภาษาปนหลายภาษา ความผิดหลายตำแหน่ง เลขโรมันทุกแบบ และงานซ้อนหลายเรื่องยังไม่ได้รับประกันทั้งหมด

ความจำใน parent อยู่ 30 นาทีตามค่าปัจจุบัน ไม่คงอยู่เองข้ามการปิด server; การรับประวัติกลับจาก client ไม่ใช่การเก็บถาวร

เส้นทางคำถามปุ่มไทยรอบแรกยังอาจผ่านการตีความของ LLM แม้ขอชื่อเกมอย่างเดียวได้ ควรเสริมทางด่วนก่อนการเรียกโมเดลสำหรับกรณีที่ intent ชัดเจนแล้ว มี outlier 14.152 วินาทีในรอบเว็บที่เก็บไว้ แยกเป็นงานปรับเวลาไม่รวมกับการรับรองความถูกต้องของเนื้อหา

ยังต้องยืนยันแหล่งข้อมูลราคา กติกา RoV ที่ต้นฉบับขาดบางข้อความ ข้อยกเว้น pause ของ Tekken และปุ่มที่ตั้งไว้บนเครื่องจริงของศูนย์ แยกจากความถูกต้องของการเลือกเส้นทางตอบ
