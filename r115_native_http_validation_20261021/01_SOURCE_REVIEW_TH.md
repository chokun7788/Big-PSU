# ขั้น 1 — ตรวจหลักฐานเดิมก่อนยิงแชทจริง

## เวลาเปิด

เจ้าของยืนยันเฉพาะวันจันทร์–ศุกร์ 16:00–18:00 ว่าปิด ไม่ได้ยืนยันช่วงเปิดทั้งหมด ตาราง native วันธรรมดา open_periods=conflicted; zone_ids และ validity ยัง unknown จึงไม่เปลี่ยนเป็นเปิด 09:00–16:00 โดยไม่มีหลักฐาน ตารางจอง/เวลาเหมาเป็นคนละ predicate

## ราคา VR

Q049 ยืนยัน “ทั้งหมดคิดต่อคน” ซึ่ง R114 ผูกกับ hash ของ rates เดิมไว้แล้ว ตาราง VR มีช่วงจำนวนคน 1–5; unit และ calculation_rule เดิมยัง unknown คำยืนยันต่อคนไม่ยืนยันส่วนลด การปัดเศษ การเพิ่ม capacity หรือ booking eligibility เกินช่วง ดังนั้นตรวจผลรวมหลายรอบตามหน่วยที่ยืนยันแยกจากการอนุญาตให้จอง และจะไม่ขยายช่วงราคา/จำนวนคนเอง

## กติกา 6 ข้อ

ไม่ได้ส่งคำถามเพิ่มหรือรันทดสอบซ้ำทั้ง 6 ข้อ ใช้คำตอบ/log เดิม อ่านย่อหน้าจาก snapshot เอกสารและตรวจ SHA/text ตรงกับต้นฉบับที่เก็บไว้ คำถามถามทั้งหัวข้อ การคืนหลายย่อหน้าหัวข้อเดียวกันจึงมีเหตุผลตาม source; คงผล strict เดิมไว้และแยกเป็นข้อบกพร่องความละเอียดของ oracle ไม่บังคับให้ตอบเพียงย่อหน้าสุ่ม

## เกณฑ์รอบ HTTP

ส่งข้อความ/locale ของคำถามเดิม 1,400 ข้อเท่านั้น ไม่มี category hint คง expected เดิม และเก็บการจับคู่ record/facet กับ native ก่อนดูคำตอบ รอบนี้ไม่ใส่ fake live/news fixture ลงฐานข้อมูลจริง ข้อ fixture ที่ไม่มี source จะแยกจากคะแนนเนื้อหาที่ตอบได้ ไม่เอาการตอบ unavailable มาบวกเป็น answered accuracy

Native facts 1421; legacy facts aligned 1164; mapping/projection gaps 0; source value/presentation differences 24

เกณฑ์ native ใช้ projection ร่วมเพื่อจัด identity/รูปแบบ จึงต้องตรวจ drift และ source แยก ไม่ใช่ independent human semantic evaluation

## C13-NEW-001

กติกาของ กฎระเบียบและรูปแบบการแข่งขัน VALORANT หัวข้อ การใช้สกิลเอเจนท์ ระบุเงื่อนไขไว้อย่างไร

- ย่อหน้า 66: ห้ามวางกล้อง Cypher ในจุดที่มองไม่เห็นหรือทำลายไม่ได้ผ่านการทะลุ Texture ของแผนที่
- ย่อหน้า 67: ห้ามใช้สกิลในพื้นที่นอกขอบเขตแผนที่ (Out of boundaries) เพื่อหาข้อมูลหรือสร้างความได้เปรียบ
- ย่อหน้า 68: ข้อยกเว้นพิเศษ สกิล ZERO/POINT ของ KAY/O สามารถใช้ภายนอกแผนที่หรือจุดที่ทำลายไม่ได้ได้ แต่ตัวมีดห้ามพุ่งทะลุ Texture ที่ควรจะเป็นของแข็ง
- ย่อหน้า 69: การกระโดดต่อตัว ห้ามใช้ตัวละครเพื่อนร่วมทีมเพื่อกระโดดไปยังจุดที่สูงเกินกว่าระยะกระโดดปกติ

## C13-NEW-002

กติกาของ กฎระเบียบและรูปแบบการแข่งขัน Counter-Strike 2 หัวข้อ พฤติกรรมและบทลงโทษ ระบุเงื่อนไขไว้อย่างไร

- ย่อหน้า 36: มารยาทผู้เล่น ห้ามพฤติกรรมก้าวร้าว วาจาสร้างความเกลียดชัง (เหยียดเชื้อชาติ/ศาสนา) และการกระทำที่ไม่มีน้ำใจนักกีฬา
- ย่อหน้า 37: การใช้บัค ห้ามใช้บัคของแผนที่หรือ Engine เกมเด็ดขาด หากฝ่าฝืนจะถูกปรับแพ้ในรอบ/แผนที่นั้น หรือตัดสิทธิ์
- ย่อหน้า 38: การดูสตรีม ห้ามผู้เล่นดูสตรีมสดระหว่างแข่ง

## C13-NEW-003

กติกาของ กฎระเบียบและรูปแบบการแข่งขัน VALORANT หัวข้อ กฎเกี่ยวกับบั๊ก ระบุเงื่อนไขไว้อย่างไร

- ย่อหน้า 55: บั๊กคือข้อผิดพลาดในเกมที่ทำให้เกิดผลลัพธ์ที่ไม่ตั้งใจ โดยแบ่งประเภทเพื่อกำหนดแนวทางปฏิบัติ ดังนี้
- ย่อหน้า 56: Play Through Bug บั๊กที่ไม่ส่งผลกระทบต่อความยุติธรรมอย่างมีนัยสำคัญ ผู้เล่นต้องเล่นต่อไปและไม่สามารถขอ Challenge ได้
- ย่อหน้า 57: Major Bug บั๊กที่ส่งผลกระทบต่อการเล่นหรือกลไกเกมอย่างมากและไม่มีทางแก้ไขเฉพาะหน้า ทีมสามารถขอ Challenge เพื่อตรวจสอบได้
- ย่อหน้า 58: Game Breaking Bug บั๊กที่ทำลายความยุติธรรมของรอบนั้นจนไม่สามารถตัดสินผลแพ้ชนะได้
