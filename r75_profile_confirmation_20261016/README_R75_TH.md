# ทดลองสำเนาพัฒนา R75

เปิด **Open-New-Chat.cmd** ในโฟลเดอร์นี้ แชทใช้พอร์ต **8109** ปิดด้วย **Stop-New-Chat.cmd** ของโฟลเดอร์นี้ แก้ข้อมูลด้วย **Open-Data-Editor.cmd** ที่พอร์ต **8110**

ยังใช้ Python runtime จากโฟลเดอร์ `PSU_Esports_Chat_New_R69` ที่อยู่ข้างกัน และ Ollama/โมเดลเดิม เปิด LLM อยู่ ชุดนี้ยังไม่ใช่ portable package ใหม่หรือ production release

## วิธีคุยกับหัวข้อที่ระบบยังแปลความหมายไม่มั่นใจ

เช่นถาม `I attached the incorrect proof of payment. How do I fix it?` ระบบจะถามยืนยันหัวข้อ “Correct an incorrect payment-slip image?” ตอบ `yes` หรือ `slip` แล้วระบบจะอ่านขั้นตอนจาก source จริง ถ้าไม่ตรง ตอบ `no` ได้

ภาษาไทย เช่น `แนบหลักฐานชำระเงินผิด ต้องแก้ยังไง` → ตอบ `ใช่ครับ` หรือ `สลิป` หลังเห็นหัวข้อที่ตั้งใจถาม

ถ้ามีหลายหัวข้อ ให้พิมพ์เลขที่แสดงหรือชื่อหัวข้อ ใช้ `ถัดไป` / `next` เพื่อดูหน้าอื่น หากหัวข้อหรือข้อมูลถูกถอน/เปลี่ยนขอบเขตระหว่างคุย ระบบจะไม่ใช้ตัวเลือกเก่า

เป็นการเลือกหัวข้อที่ต้องการถาม ไม่ใช่การอนุมัตินโยบาย ข้อมูลจริงและสถานะ draft/approval ยังคงเดิม

## ผลและงานที่เหลือ

อ่าน `REPORT_R75_TH.md`, `FLOW_R75_TH.md` และ `REMAINING_WORK_R75_TH.md`

ผ่านชุดหลัก 43/43, scope 50/50, confirmation/state/fixture 28/28 และ language checks 16/16 ไม่รวมเป็น accuracy เดียว
