## ข้อสรุป

การเพิ่ม Format กลางไม่ได้ย้ายความสามารถตีความคำถามของ Legacy มาด้วยทั้งหมด ต้องทำตัวตีความงานร่วมกับตัวอ่านข้อมูลกลาง โดยแยกการตีความ การเชื่อมข้อมูล ความเพียงพอของหลักฐาน และการจัดคำตอบให้ตรวจได้ทีละชั้น

R95 ได้ 18,579/24,909 เกณฑ์ข้อความเชิงบวก เทียบ Legacy R64 ที่ 23,517/24,909 เกณฑ์เดียวกัน ยังห่าง 4,938 เกณฑ์สุทธิ ไม่ใช่จำนวนคำถามที่ผิดสาระจริง

เมื่ออ่าน log R95 ที่มีอยู่ พบ 2,745 คำถามที่มีเกณฑ์ข้อความเชิงบวกไม่ผ่านอย่างน้อยหนึ่งรายการ แบ่งเป็นปัญหาที่ต้องแก้ต่างกัน เช่น ข้อมูลหมดช่วงมีผล การถามกลับ การเลือก field ไม่สำเร็จ และคำตอบที่ต้องตรวจว่าต่างถ้อยคำหรือผิดสาระ

## ขอบเขตการค้น

เรียกใช้ paper-search-pro และตรวจ setup แล้ว แต่ไม่มี OpenAlex API key และ NCBI email จึงหยุด workflow ตัวช่วยตามข้อกำหนดของสกิล แล้วค้นจากเว็บแหล่งต้นฉบับโดยตรงแทน มีการค้นเจาะปัญหา 20 queries และคัดงานหลัก 15 ชิ้น อ่านบทคัดย่อ/ข้อมูลตีพิมพ์ของชุดหลัก และส่วนวิธีการ/ข้อจำกัดของงานสำคัญเพิ่มเติม

ไม่ได้ทำ multi-database crawl, classifier batches, saturation estimation, PRISMA-S หรือรายงาน HTML ของสกิล จึงไม่อ้างว่าเป็น Standard/Deep ที่ทำครบ หรือค้นครอบคลุมวรรณกรรมทั้งหมด หากตั้งค่าแล้วสามารถทำ workflow เต็มของสกิลเสริมได้ รายงานนี้เพียงพอสำหรับออกแบบสมมติฐานแก้ระบบ แต่ไม่ใช่ systematic review

บทความเป็นหลักฐานประกอบการออกแบบ ไม่รับรองว่าจะย้ายผลทดลองของบทความมาได้บน Typhoon 4B / ไทย / ข้อมูลศูนย์นี้

## การรักษาหลักฐาน

อ่านผล R64/R88/R95 และโค้ด R95 เท่านั้น ไม่เปลี่ยน source data, approvals, frozen runtime, oracle หรือตัวตรวจเก่า เก็บ hash ของไฟล์ที่ใช้ใน `READ_ONLY_SOURCE_MANIFEST.json` สคริปต์ `analyze_saved_evidence.py` อ่าน log ที่มีอยู่ ไม่มีการ import chatbot หรือเรียกโมเดล
