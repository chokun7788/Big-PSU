# แบบตอบคำถามเจ้าของ R107

## หน้าแบบย่อ — ใช้งานปัจจุบัน

หน้าเว็บปัจจุบันมี 56 คำถามกับช่องใส่คำตอบเท่านั้น: 47 คำถามนโยบายที่ยังขาด และ 9 คำถามรวมของราคา/เอกสารแข่งขัน/บุคลากร/ผังปุ่ม/inventory ไม่ต้องเลือกสถานะหรือกรอกช่องเทคนิค รายการซ้ำจากแบบเดิมถูกรวมเพื่อให้ตอบครั้งเดียว ไม่ได้ถือว่าแก้ข้อมูลที่ยังขาดไปแล้ว คำถามชื่อเล่นเกมกำกวม 2 กลุ่มเก็บไว้เป็นงานเทคนิค ไม่ขอเจ้าของตอบในหน้านี้

พิมพ์เฉพาะคำตอบส่วนที่ถาม ข้ามข้อที่ยังไม่พร้อมได้ ร่างเก็บใน `responses/simple_answers.json` เมื่อกด **ส่งคำตอบ** ระบบเก็บชุดที่ส่งใน `responses/submissions/` และดาวน์โหลดไฟล์ JSON ให้นำไปแนบในแชทได้ คำถามที่ส่งแล้วจะไม่แสดงซ้ำเมื่อเปิดใหม่

คำตอบเดิม 36 ข้อและหลักฐานใน `responses/answers.json` ยังเก็บไว้ ไม่ถูกเขียนทับด้วยข้อความเพิ่มเติมจากหน้าแบบย่อ แบบฟอร์มละเอียดก่อนแก้อยู่ใน `before_simple_form/` ไม่มีการนำคำตอบใหม่เข้า production อัตโนมัติ

## อัปเดตหลังรับคำตอบชุด 50 ข้อ

จับคู่คำตอบให้แล้ว 36 ข้อในแบบฟอร์ม: ตอบครบ 5 ข้อ และตอบบางส่วน 31 ข้อ เหลือ 297 ข้อที่ต้องตอบ/เติม (266 ข้อยังไม่มีคำตอบเฉพาะข้อ + 31 ข้อที่เหลือเฉพาะเงื่อนไขเพิ่ม)

- เว็บเปิดตัวกรอง “ยังต้องตอบ / เติมส่วนที่ขาด” เป็นค่าเริ่มต้น
- สถานะ “ตอบแล้วบางส่วน” แสดงคำถามเฉพาะส่วนที่ยังขาดด้านบน และเก็บคำตอบเดิมไว้ในช่องแก้ไข ให้พิมพ์ต่อท้ายแล้วเลือก “ให้คำตอบแล้ว” เมื่อครบ
- ดูรายการที่เหลือใน `REMAINING_QUESTIONS_TH.md`
- หลักฐานคำตอบจากแชทอยู่ใน `owner_update_50/SOURCE_OWNER_50.json` และการจับคู่ใน `owner_update_50/MATCHING_REPORT_TH.md`
- ใช้คำตอบใหม่ว่าคีย์บอร์ด/เมาส์ส่วนตัวนำมาใช้ได้แต่ต้องแจ้ง แทนข้อความห้ามเก่า เฉพาะแบบฟอร์มและข้อมูลอ้างอิงใหม่นี้ ไม่แก้ฐานแชทจริงหรือกฎการแข่งขันโดยอัตโนมัติ
- ถ่ายภาพ/วิดีโอในเกมอนุญาตและต้องลบหลังเสร็จ ยังไม่ยืนยันการถ่ายภาพสถานที่หรือบุคคล
- คำตอบจากเว็บที่มีอยู่ก่อนเติมจะไม่ถูกเขียนทับ บันทึกประวัติและ snapshot สำรองไว้

เปิด `Start-Owner-Questions.cmd` แล้วตอบในเว็บได้เลย ใช้ Python ที่มีอยู่ในโครงการ ไม่เรียก LLM และไม่ต้องดาวน์โหลดโมเดล

## สิ่งที่รวมไว้

- 52 คำถามนโยบายที่ยังขาด/ขัดกัน
- 187 รายการเดิมที่ต้องตรวจเงื่อนไขเพิ่ม: ราคา 24, ราคาเหมา 24, เอกสารแข่งขัน 4, ข้อกติกา 104, บุคลากร 25 และประเด็นแยกไว้รอตรวจ 6
- 63 ข้อมูลเสริม: อายุ/ค่าสมัคร/พฤติกรรมแข่ง 12, ผังปุ่ม/เวอร์ชัน 43, inventory ของบริการ 8
- 25 เรื่องที่มีคำตอบแล้ว เก็บให้เปิดดู ไม่ต้องตอบซ้ำ

นี่คือรายการประเด็นที่ทราบว่ายังขาด ณ 20 ตุลาคม 2026 ไม่ได้อ้างว่าเป็นคำถามที่อาจเกิดได้ทั้งหมดในอนาคต งานแก้ Flow, evaluator, renderer และ transport ไม่ถูกผลักให้เจ้าของตอบ

## วิธีตอบ

1. เริ่มกลุ่ม **คำถามนโยบาย** หรือเลือกหมวดที่ทราบก่อน
2. เปิดดูข้อมูลเดิมเมื่อเกี่ยวข้อง ไม่ต้องคัดลอกข้อมูลเดิมซ้ำ
3. พิมพ์คำตอบตามตัวอย่าง แล้วเลือกสถานะ “ให้คำตอบแล้ว”
4. ถ้ายังไม่รู้ ใช้ “ยังไม่ทราบ”; ถ้ายังไม่มีข้อกำหนดจริง ใช้ “ยังไม่มีนโยบาย” — สองสถานะนี้ไม่ใช่การอนุญาต
5. ใส่ประกาศ/เลขหน้า วันเริ่มใช้/วันสิ้นสุด และแนบเอกสารเมื่อเกี่ยวข้อง
6. รอข้อความ “บันทึกในเครื่องแล้ว” หรือกดบันทึกข้อนั้น
7. จะกลับมาตอบต่อก็เปิดไฟล์เดิม คำตอบอยู่ใน `responses/answers.json`
8. กด “ดาวน์โหลดคำตอบ JSON” หรือ “คัดลอกสรุปส่งในแชท” เพื่อให้ตรวจและจัดเข้า format กลางต่อ

เว้นวันสิ้นสุดไว้ไม่แปลว่าไม่มีวันสิ้นสุด หากไม่กำหนดให้เขียนในคำตอบ explicitly; วันที่กรอกไม่ใช่วันที่นโยบายเริ่มมีผล

## ที่เก็บคำตอบ

- `responses/answers.json`: คำตอบปัจจุบัน
- `responses/events.jsonl`: ประวัติการบันทึกใหม่ เก็บค่าแต่ละครั้งเพื่อกู้ได้
- `responses/attachments/`: ไฟล์แนบจริง (สูงสุด 20 MB ต่อไฟล์)
- JSON export มี metadata ไฟล์แนบ แต่ไม่มีเนื้อไฟล์แนบทั้งหมด หากย้ายเครื่องให้เก็บทั้งโฟลเดอร์ responses ด้วย
- นำเข้า JSON ของชุดนี้ได้ การนำเข้าจะสำรองคำตอบเดิมก่อน และไม่ดึงไฟล์แนบจากเครื่องอื่นเอง

เว็บนี้ฟังเฉพาะ 127.0.0.1 เลือกพอร์ตว่าง 8120–8139 เก็บคำตอบแยกจากฐานข้อมูลแชทจริง ไม่มีการอนุมัติ/เผยแพร่/เปลี่ยนกฎหรือราคาอัตโนมัติ

`QUESTIONS_TH.md` รวมรายการคำถามทั้งหมดสำหรับอ่านหรือส่งต่อ และ `questions.json` เก็บรหัสรายการกับหลักฐานต้นทางสำหรับจัดข้อมูลต่อ ไม่ได้แก้ frozen R106
