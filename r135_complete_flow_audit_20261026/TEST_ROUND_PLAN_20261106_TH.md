# แผนรอบแก้และทดสอบ R135

เป้าหมายคง 76 ข้อ/14 หมวด บันทึกแยกสิ่งที่ตรวจแล้ว สิ่งที่แก้ และสิ่งที่ผ่านการตรวจรับ

1. **โจทย์และคำตอบ:** รวมปัญหาการแยกคำถามหลายส่วน การอ้างอิงเป้าหมาย และการตอบตรงประเด็น ทดสอบคำถามที่ล้ม กรณีปกติ กรณีกำกวม และคำถามหลายส่วนที่เกี่ยวข้อง
2. **ราคาและการจอง:** รวมปัญหาขอบเขตจำนวนคน ยอดรวม หลายบริการ วันเวลา และขั้นตอนจอง ทดสอบราคาเดี่ยว ราคาแบบหลายส่วน ข้อมูลที่ไม่ครบ และการจองที่เกี่ยวข้อง
3. **เพิ่ม แก้ ถอนข้อมูล:** ตรวจตั้งแต่เพิ่มข้อมูลในสำเนา แก้แล้วตอบฉบับใหม่ ถอนแล้วไม่ใช้ฉบับถอน ตลอดจนกรณีข้อมูลไม่ยืนยัน โดยใช้หลักฐานเดิมเมื่อเวอร์ชันและข้อมูลตรงกัน
4. **หมวดอื่นและงานรวม:** จัดกลุ่มตามสาเหตุร่วม ตรวจเฉพาะผลกระทบและข้อกำหนดที่ยังค้าง พร้อมรักษาความครอบคลุมทั้ง 14 หมวด

แต่ละกลุ่ม: เก็บผลก่อนแก้ที่มีอยู่ แก้ร่วมกัน แล้วรันกรณีที่เคยล้ม กรณีปกติและกรณีปฏิเสธที่จำเป็น และ regression เฉพาะส่วนที่เปลี่ยนหนึ่งรอบ ขยายเมื่อพบปัญหาหรือความเสี่ยงจริง ไม่รันซ้ำเมื่อ input และ dependency ไม่เปลี่ยน เมื่อแนวทางล้ม ให้บันทึกและเปลี่ยนแนวทางหรือถอน ห้ามวนเหมือนเดิม

หลังกลุ่ม 1–3 รวมเข้าด้วยกันและผ่านการตรวจเฉพาะส่วน ให้รันตัวอย่าง 10% หนึ่งรอบกับ candidate ที่ระบุเวอร์ชันและข้อมูลชัดเจน เก็บผลดิบและ log แยก แล้วสรุปความครอบคลุม คะแนนตามเกณฑ์ที่ตรวจได้ และข้อที่ยังประเมินไม่ได้ เทียบกับผลเก่าที่จับคู่ได้โดยระบุความต่างของเวลา ข้อมูล และสภาพแวดล้อม ไม่ rerun หรือ regrade R132

รอบ 10% นี้เป็นจุดตรวจกลาง ไม่ใช่การรับรองทั้งระบบ หลังจากนั้นแก้กลุ่มปัญหาจริงที่พบ จึงค่อยตรวจรวมและเกณฑ์ติดตั้งตามขอบเขตเดิม ห้ามนำข้อมูลทดสอบไปทับข้อมูลจริง
